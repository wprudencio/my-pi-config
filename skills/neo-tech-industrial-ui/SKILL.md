# Neo-Tech Industrial UI

## Quick start

```html
<!-- Fonts (include in <head>) -->
<link href="https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@400;500;600;700&family=IBM+Plex+Mono:wght@400;500;600;700&display=swap" rel="stylesheet">
```

```css
/* Core variables */
:root {
  --tech-lime: #D7FF00;
  --graphite: #2B2B2B;
  --soft-gray: #BDBDBD;
  --deep-black: #050505;
  --off-white: #F5F5F5;
  --signal-red: #FF4D4D;
  --electric-cyan: #00E5FF;
  --warning-orange: #FF9900;
}
```

## Core principles

1. **Typography** — Space Grotesk for headings/UI; IBM Plex Mono for metadata, labels, coordinates, serial numbers, technical annotations. Use uppercase titles, bold geometric headings, compact letter-spacing (0.06–0.12em).

2. **Color** — Neon lime (#D7FF00) as primary accent on grayscale/deep-black backgrounds. Add signal-red, electric-cyan, or warning-orange sparingly. No gradients, no soft shadows, no colorful palettes.

3. **Layout** — Asymmetrical, modular, information-dense. Everything should feel like machine labels, industrial stickers, or system modules. Use offset blocks, floating panels, uneven spacing. Avoid perfectly centered or symmetrical layouts.

4. **Components** — Panels with 1px borders and lime accent lines. Cards with dark backgrounds (#3A3A3A) and thin separators. Buttons in lime fill with black border, uppercase, 0.08em letter-spacing, weight 700. Hover: color inversion or blinking border.

5. **Decoration** — Wireframe shapes, thin lines, circles, grids, barcodes, scanlines, technical annotations, coordinate systems, CRT noise overlays. Avoid gradients, glassmorphism, neumorphism, cartoons.

6. **Animation** — Mechanical and digital: blinking indicators, scanning movement, linear transitions, segmented loading bars. No bouncy or playful easing.

## Workflow

1. Read [REFERENCE.md](REFERENCE.md) for full color system, typography specs, component recipes, and texture effects.
2. Embed Space Grotesk and IBM Plex Mono from Google Fonts.
3. Set CSS custom properties from the color system.
4. Build layout as asymmetrical panels — never center content.
5. Style every UI element as a machine label or system module.
6. Add at least one decorative element: barcode, scanline, wireframe circle, or grid overlay.
7. Add at least one animation: blinking dot, scanning line, or pulsing indicator.
8. Use uppercase and monospace for all metadata, labels, and technical text.
